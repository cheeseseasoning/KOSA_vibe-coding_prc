# OUR TEAM — Portfolio

**세 사람의 개성으로 함께 만드는 포트폴리오.**

AI와 대화하며 각자의 자기소개 페이지를 제작하고, GitHub로 작업을 통합한 KOSA 바이브 코딩 실습 프로젝트입니다.

## 프로젝트 목표

- 바이브 코딩의 개념과 활용 방법을 이해한다.
- AI를 활용해 자기소개 페이지를 직접 제작한다.
- Git과 GitHub로 브랜치 생성, 커밋, PR, 병합을 경험한다.

## 팀원 및 페이지

| 팀원 | 페이지 |
| --- | --- |
| 최희조 | [자기소개 페이지](members/intro_hj.html) |

공통 메인 페이지의 팀원 카드를 통해 각자의 포트폴리오로 이동할 수 있습니다.

## 페이지 구성

### 팀 메인

흑백 중심의 색상과 카드형 레이아웃으로 구성했습니다. 팀원별 페이지로 이동하는 링크와 마우스 효과를 적용하고, 작은 화면에서는 카드가 세로로 배치되도록 만들었습니다.

### 개인 포트폴리오

각자의 스타일에 맞춰 소개, 관심 기술, 학습 경험, 프로젝트 등을 담았습니다. 개인 페이지는 독립적으로 수정하고 발전시킬 수 있도록 구성했습니다.

## 사용 도구

- **HTML / CSS**: 페이지 구조와 디자인 구현
- **VS Code**: 코드 작성 및 수정
- **Git / GitHub**: 버전 관리와 팀 협업
- **AI 코딩 도구**: 코드 초안 작성, 디자인 개선, 오류 원인 파악

## 폴더 구조

```text
KOSA_vibe-coding_prc/
├─ index.html              # 팀 메인 페이지 — CSS 포함
├─ members/
│  ├─ intro_hj.html        # 최희조 포트폴리오
│  ├─ intro_yj.html        # 김용진 포트폴리오
│  └─ intro_jo.html        # 이준오 포트폴리오
├─ css/
│  ├─ hj.css               # 최희조 페이지 스타일
│  ├─ main.css             # 이준오 페이지 스타일
│  └─ style.css            # 초기 공통 스타일
├─ js/
│  └─ main.js              # 초기 스크립트
└─ README.md
```

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 폴더의 `index.html`을 브라우저에서 엽니다.
3. 팀원 카드를 선택해 개인 페이지를 확인합니다.

별도의 설치나 빌드 없이 실행할 수 있습니다.

## 협업 과정

1. 공통 프로젝트의 기본 구조를 준비했습니다.
2. 개인 브랜치를 만들어 각자의 자기소개 페이지를 제작했습니다.
3. 변경 사항을 커밋하고 GitHub에 업로드했습니다.
4. Pull Request를 통해 팀원 작업을 공유하고 병합했습니다.
5. 별도 브랜치에서 팀 메인 페이지를 개선했습니다.
6. 팀원 페이지를 통합하며 파일 위치와 연결 경로를 정리했습니다.

## 실습에서 배운 점

- **AI와 반복적으로 개선하기**  
  원하는 분위기를 이미지와 문장으로 설명하고, 결과를 확인하며 색상·글자 크기·배치를 조정했습니다.

- **상대 경로 이해하기**  
  HTML 파일을 `members` 폴더로 이동하면서 CSS와 Home 링크에 `../`가 필요한 이유를 확인했습니다.

- **병합 충돌 해결하기**  
  같은 `index.html`을 수정하면서 발생한 충돌을 확인하고, 메인 디자인과 팀원 링크를 함께 유지하도록 정리했습니다.

- **직접 확인하며 개발하기**  
  AI가 제공한 코드를 직접 적용하고 브라우저에서 확인하며, 수정 사항을 Git으로 기록했습니다.

## 앞으로의 개선

- 개인 소개와 프로젝트 내용을 보완하기
- 임시 연락처 및 저장소 링크를 실제 정보로 변경하기
- 모바일 화면과 페이지 이동을 점검하기
- GitHub Pages로 웹사이트 공개하기
